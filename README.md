# Text Diff Tool

Консольное приложение для сравнения двух текстов с помощью модуля `difflib`.

## Описание

Этот инструмент позволяет сравнивать два текста и визуально отображать различия между ними. Программа использует цветовую индикацию для лучшего восприятия изменений:
- Зеленым цветом выделяются добавленные строки
- Красным цветом выделяются удаленные строки

## Требования

- Python 3.x
- Модуль `difflib` (входит в стандартную библиотеку Python)

## Использование

```bash
# Перейдите в директорию с программой
cd /Users/pavelkacan/diff_files

# Запустите программу одним из способов:
# 1. Через python3 (рекомендуемый способ):
python3 text_diff.py "первый текст" "второй текст"

# 2. Напрямую (если файл имеет права на выполнение):
./text_diff.py "первый текст" "второй текст"
```

### Примеры

1. Сравнение однострочных текстов:
```bash
python3 text_diff.py "Привет мир!" "Привет новый мир!"
```

2. Сравнение многострочных текстов:
```bash
python3 text_diff.py "Первая строка\nВторая строка" "Первая строка\nНовая строка\nТретья строка"
```

3. Сравнение текстов из файлов:
```bash
python3 text_diff.py file1.txt file2.txt
```

## Особенности

- Поддержка многострочного текста
- Цветовая индикация различий
- Подробное отображение изменений в похожих строках
- Простой и понятный интерфейс командной строки
- Возможность чтения текстов как из аргументов командной строки, так и из файлов 

## Установка на macOS

1. Скачайте `TextDiff.app` из последнего релиза
2. Откройте Terminal
3. Перейдите в директорию с `TextDiff.app`
4. Выполните команды:
   ```bash
   chmod +x TextDiff.app/Contents/MacOS/TextDiff
   xattr -d com.apple.quarantine TextDiff.app
   ```
5. Запустите приложение двойным кликом или через Terminal:
   ```bash
   open TextDiff.app
   ```

### Системные требования для macOS
- macOS 10.15 (Catalina) или новее
- 4GB RAM
- 100MB свободного места на диске 

## Установка на Windows

1. Скачайте `text_diff_gui.exe` из последнего релиза
2. Если файл заблокирован Windows Defender:
   - Правый клик по файлу → Properties
   - Поставьте галочку "Unblock"
   - Нажмите OK
3. Запустите приложение двойным кликом или через командную строку:
   ```cmd
   text_diff_gui.exe
   ```

### Системные требования для Windows
- Windows 10 или новее
- 4GB RAM
- 100MB свободного места на диске 

## Kotlin/Compose Multiplatform версия

Проект также доступен в версии, написанной на Kotlin с использованием Compose Multiplatform. Эта версия предоставляет единый код для всех платформ (Windows, macOS, Linux) с нативным UI.

### Требования для разработки

- Kotlin 1.9.20 или новее
- JDK 17 или новее
- Gradle 8.0 или новее

### Сборка

```bash
# Сборка для всех платформ
./gradlew build

# Сборка для конкретной платформы
./gradlew desktopRun    # Для Windows/Linux
./gradlew macosRun      # Для macOS
```

### Особенности Kotlin/Compose версии

- Единый код для всех платформ
- Современный Material 3 дизайн
- Асинхронная обработка сравнения текстов
- Нативная производительность
- Поддержка тёмной темы
